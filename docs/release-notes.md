Пошаговые инструкции строительства: 3D, схемы слоёв, материалы. Работает без интернета, без рекламы и без сбора
данных.

## Что скачать

| Система               | Файл                                        |
| --------------------- | ------------------------------------------- |
| Windows               | `.msi` или `-setup.exe`                     |
| Linux                 | `.deb` (Ubuntu, Debian) или `.AppImage`     |
| macOS (Apple Silicon) | `.dmg` с `aarch64` в имени                  |
| macOS (Intel)         | `.dmg` с `x64` в имени                      |
| Android               | `app-release.apk`                           |
| Без установки         | https://cacheshellpassage.github.io/kladka/ |

Файл `.aab` нужен только магазинам приложений, скачивать его не нужно.

## Первый запуск

У установщиков нет платной подписи разработчика, поэтому система переспросит:

- **Windows**: в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае».
- **macOS**: правый щелчок по приложению → «Открыть» → «Открыть».
- **Android**: разрешите установку из этого источника, когда телефон спросит.

## Что нового

Первая версия: 36 построек, 3D с режимом «Шейдеры», схемы слоёв с экспортом в PNG и PDF, материалы с чек-листом,
режим «Я в игре», паспорт постройки, импорт и экспорт .schem, .litematic и .nbt.
