Пошаговые инструкции строительства: 3D, схемы слоёв, материалы. Работает без интернета, без рекламы и без сбора
данных.

## Что скачать

| Система               | Файл                                        |
| --------------------- | ------------------------------------------- |
| Windows               | `.msi` или `-setup.exe`                     |
| Linux                 | `.deb` (Ubuntu, Debian) или `.AppImage`     |
| macOS (Apple Silicon) | `.dmg` с `aarch64` в имени                  |
| macOS (Intel)         | `.dmg` с `x64` в имени                      |
| Android               | `app-release.apk`                           |
| Без установки         | https://cacheshellpassage.github.io/kladka/ |

Файл `.aab` нужен только магазинам приложений, скачивать его не нужно.

## Первый запуск

У установщиков нет платной подписи разработчика, поэтому система переспросит:

- **Windows**: в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае».
- **macOS**: правый щелчок по приложению → «Открыть» → «Открыть».
- **Android**: разрешите установку из этого источника, когда телефон спросит.

## Что нового

Версия 1.0.1 — шаги стало удобнее строить:

- Дом растёт по этажам: каркас, стены и окна ставятся вместе, слой за слоем, а лестницы — сразу со стенами, а не
  после крыши. Блоков, до которых не дотянуться с земли или с готового этажа, стало заметно меньше.
- Новый первый этап «Участок»: газон, земля и тропинки. Если земля на месте уже есть, его можно пропустить одной
  кнопкой. Блок травы в материалах теперь считается как земля — «Шёлковое касание» не нужно.
- Мебель и декор собираются по комнатам и уголкам, а не россыпью по слоям: меньше шагов из одного-двух блоков.
- Исправлены лестницы в пяти постройках каталога: они висели на стекле или решётке, а в игре так поставить нельзя.

Сохранённый прогресс в уже начатых постройках может сдвинуться: шаги разбиты по-новому.

installers are not signed with a paid certificate: on Windows choose "More info" → "Run anyway", on macOS right-click →
"Open".

New in 1.0.1: houses rise floor by floor with ladders built together with the walls, the plot ground is a first
stage you can skip, furniture and decor are grouped by room, and ladders in five catalogue builds are fixed.
