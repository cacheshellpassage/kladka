# Итоговый отчёт (2026-11-07)

## Что сделано

- **Монорепозиторий** (pnpm, TypeScript strict, ESLint, Prettier, Vitest, Playwright), 6 коммитов по этапам.
- **voxel-core:** свой NBT-кодек; импорт `.schem` v1–v3, `.litematic` v4–v7 (многорегионные), `.nbt`, `.kbuild`;
  экспорт `.schem` v3/v2, `.litematic` v7, `.nbt`; знания о блоках MC Java 26.3 (формы, материалы, предметы,
  ru/en-названия); «умные этапы» с симуляцией установки блоков; материалы; оценка сложности и времени.
- **viewer:** three.js, процедурные текстуры, greedy meshing по чанкам 32³, отсечение граней с учётом шагов,
  срезы, режимы «Обычный» и «Шейдеры» (тени, GTAO, bloom, день/закат/ночь), автокамера и авторазрез для интерьера.
- **content:** 36 оригинальных построек (CC0), все проходят проверку «можно построить руками без лесов».
- **Превью:** classic + cinematic, 4 ракурса и миниатюры для каждой постройки (`pnpm render:previews`).
- **Приложение:** каталог, карточка, пошаговый режим (3D + схема слоя, PNG/PDF), свободный 3D, импорт/экспорт,
  настройки (язык, тема, качество, левша, масштаб текста, свой ресурспак/client.jar), справка, политика.
- **Оболочки:** Tauri 2 (desktop), Capacitor 8 (Android, подпись через keystore.properties/секреты), PWA.
- **CI:** проверки + веб + E2E; Tauri для Windows/Linux/macOS; Android APK (debug/release) и AAB.
- **Документация:** README ru/en, ARCHITECTURE, FORMATS, CONTENT, DECISIONS, LEGAL, RUSTORE, SHADER_SCREENSHOTS,
  THIRD_PARTY_LICENSES.

## Что не проверено и почему

- **Tauri-сборки и Android APK/AAB** не собирались локально: на машине нет Rust, VS Build Tools и Android SDK
  (по выбору владельца). Конфигурация и workflows готовы, но ещё не запускались — репозиторий не отправлен на GitHub.
- **Запуск на реальном Android-устройстве** и производительность на слабом телефоне.
- **Открытие экспортированных файлов в игре** (Litematica/WorldEdit/структурный блок): форматы проверены
  тестами по спецификациям, побитово против алгоритма Litematica и через prismarine-nbt, но не в самой игре.
- **Python-кросс-проверка (litemapy/nbtlib):** скрипт есть (`tools/crosscheck_litemapy.py`), Python на машине нет.

## Что нужно сделать вам вручную

1. Создать репозиторий на GitHub, отправить код и дождаться зелёного CI (возможно, понадобится поправить версии actions).
2. Создать ключ подписи и добавить секреты (`docs/RUSTORE.md`, раздел 2).
3. Утвердить финальное название, иконку и `applicationId` (сейчас «Кладка», `app.kladka.guide`).
4. Аккаунт разработчика RuStore, карточка (тексты готовы), политика конфиденциальности на любой странице.
5. Проверить APK на телефоне и экспортированный `.litematic` в игре.

## Рекомендуемые следующие шаги

1. Прогнать CI и проверить APK на 2–3 реальных телефонах (включая слабый), подобрать качество графики по умолчанию.
2. Проверить экспорт в игре 26.x с Litematica и WorldEdit; добавить конвертер старых MCEdit `.schematic`.
3. Расширить контент и UX: больше построек (в т.ч. крупные 60–100 блоков), отметка выполненных блоков тапом
   в 3D, режим «срез ближней стены» для узких помещений.
